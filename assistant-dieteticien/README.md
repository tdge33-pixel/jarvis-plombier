# Assistant Diététicien (nom provisoire)

Projet indépendant de Jarvis Plombier, rangé dans ce dossier dédié.

**Idée :** une IA écoute la consultation (avec l'accord du patient), rédige un résumé
général et pré-remplit automatiquement la fiche de renseignements du praticien.
Le praticien n'a plus de notes à prendre : il relit, corrige et valide.

Cible de départ : les diététiciens (France), puis les autres métiers à fiche de
premier rendez-vous (kinés, psychologues, orthophonistes, etc.).

## Statut

Cahier des charges du MVP rédigé, en attente de relecture par des diététiciens. Aucun code pour l'instant.
